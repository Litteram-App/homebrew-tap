# Litteram Homebrew tap

[Litteram](https://litteram-app.github.io) is a fast, native Markdown editor for macOS with live preview.

## Install

```bash
brew install --cask litteram-app/tap/litteram
```

## Update

```bash
brew upgrade --cask litteram
```

Litteram is signed for local use only (no Apple Developer ID), so the cask removes the quarantine flag after installing: the app opens right away, with no "Open Anyway" step.

Requires macOS 15 or later.
